2. What the software is

Wingman is a free, open-source EVE Online wormhole multiboxing toolkit that runs on your own Windows PC. It mirrors running EVE clients into preview windows and switches between them, sends the wormhole mapping and rolling keybinds you configure, watches your EVE gamelogs for combat alerts and fleet combat activity, helps you prepare profiles, skills and fittings, and reviews, stitches and uploads the fight footage you select to your own YouTube channel.

It is a local tool. There is no FlyGD backend, no hosted service, no user account system and no subscription. Nothing in these terms should be read as a promise of a service, because there is no service to provide, only software you run yourself. The software is provided free of charge, and we do not accept payment for it.

The official Wingman build acts on explicit user input. It can mirror and activate EVE clients, send a configured bookmark keybind when the user presses it, read local files, and use authorized ESI operations. It does not make gameplay decisions or operate clients without user input. This description does not limit the rights to run, study, modify, or redistribute the software granted by GPL-3.0-only.

Your use of EVE Online itself remains governed by CCP's own agreements and policies, including CCP's rules on third-party tools. Deciding whether a given configuration is acceptable under those rules is between you and CCP.

5. Credentials on your PC

Wingman stores the credentials you give it on your own computer, and the protection differs by credential. Keeping your PC and your Windows account secure is your responsibility.

  • Google OAuth tokens and any Discord webhook URL are stored in plain text in the application's data folder. They are not encrypted by the application, and Wingman does not use Windows Credential Manager. Anyone who can read your Windows user profile, or who obtains a copy of it, can use them.
  • EVE refresh credentials are protected with Windows DPAPI before they are written, scoped to your Windows user account, so a copy taken to another machine or another user account cannot be unwrapped.

A Discord webhook URL is a bearer credential that does not expire; the only way to revoke it is to delete the webhook in Discord. The Privacy Policy describes exactly what is stored where, and how to revoke Google and EVE access.

CCP Games, EVE SSO and ESI

The EVE features read files that EVE Online writes on your own computer, mirror and activate running EVE client windows, and send the keystrokes you configured to the clients you enabled. Skills and Fittings additionally use EVE SSO and ESI, CCP's own authorization and third-party API services, for the characters you authorize. Wingman requests read access to skills, the skill queue and fittings, plus one additive fitting write that runs only when you select fits and target characters and confirm the copy.

EVE Online is a product of CCP hf., and your use of the game, of EVE SSO and of ESI is governed by CCP's own agreements, including CCP's developer and third-party application terms. This project uses no EVE Online artwork, assets or intellectual property. Wingman is not endorsed by CCP, and CCP may change or withdraw ESI access at any time.

Discord

The combat-log feature posts to a Discord webhook that you create and configure. Your use of Discord is subject to the Discord Terms of Service and Discord Privacy Policy. If you do not configure a webhook, the software never contacts Discord.

GitHub

Releases, source and the issue tracker are hosted on GitHub, and the application checks GitHub for release information and downloads installers and the optional plugin from there. Your use of GitHub is subject to GitHub's Terms of Service. We do not control GitHub's availability, and a release or the repository could become unreachable for reasons outside our control.

Microsoft WebView2

Wingman's interface runs in the Microsoft Edge WebView2 runtime, which is Microsoft software with its own terms. If the runtime is missing at installation time, the installer runs Microsoft's bundled bootstrapper, which downloads it from Microsoft. Without that runtime the application will not start.

OBS Studio and the optional FightRecorder plugin

Wingman reads OBS Studio's configuration to find your recording folder and watches the files OBS produces. It is not part of the OBS project, and OBS Studio is separate software with its own licence and terms that you must obtain and use accordingly.

FightRecorder is an optional OBS plugin published from a separate repository. Wingman can check for it, install it and update it when you ask, which places the plugin file in OBS Studio's plugin folder and may prompt for one Windows elevation. It is separate software under its own licence and terms, and installing it is your choice.
